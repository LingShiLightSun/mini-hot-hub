## hot.ts 改为「严格不回退 Mock」
- 用户要求：未登记后端路由或请求失败时，不要静默回退 Mock，要把问题显现出来
- 经确认选「严格不回退」：所有平台都须从后端取真实数据；知乎/B站当前未接入也会显错误态
- `fetchHotPlatform(source)` 重写为严格模式：
  - 未登记路由 -> 返回 `error:true` + message「平台「X」尚未接入后端数据源，无法加载」
  - 已登记但 `!res.ok` -> message「后端返回错误（HTTP x），请稍后重试」
  - 网络异常 catch -> message「无法连接后端（route），请确认服务已启动」
  - 仅 2xx 且解析成功才返回正常数据
  - 用 `toErrorPlatform()` 构造错误态 HotPlatform（`error:true`+`message`），交给 HotCard 以错误态呈现（message + 重试按钮），`sourceName` 用本地 `SOURCE_LABELS` 仅作展示，不再 import mock
- 删除 `getMockPlatform` 与 mock 数据依赖；`fetchAllHot()` 聚合路径保留（仅 VITE_API_BASE 配置时试 `GET /api/hot`），否则逐平台 `fetchHotPlatform`
- 效果：开发中微博走后端成功；知乎/B站因未登记 → 错误态（不再有 Mock 假数据）。HotCard 已支持 error 态（msg+重试），无需改 Home/HotCard
- 验证：`npx tsc --noEmit` exit 0；后端 3001 在线，weibo=200
