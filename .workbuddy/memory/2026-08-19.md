## 标签悬停可见性二次打磨
- **用户反馈**：选中态明显，但悬停态仍不显眼。
- **根因诊断（关键）**：标签栏直接坐在**页面奶油底 #FBF6EC** 上；首版悬停用了列表白卡上的 #FCF4E8，奶油叠奶油≈无反馈。不像列表（白卡上才看得见）。
- **修法**（非无脑加暗）：悬停底改为**明显深于页面底**的 #F5EAD9 + 极轻暖影(0 1px 4px rgba(176,125,59,.10)) 让其「浮起」；选中态也顺势加深到 #EFE0C8，使 hover / active 层级分明。
- **经验**：同一颜色在不同表面（白卡 vs 奶油底）可见性天差地别，调悬停底色必须对照它所在的实际背景，而非照搬别处的同名牌。

## 桌面奶黄气泡（tooltip）不显示的 bug 修复
- **用户反馈**：悬停被截断的标题，气泡根本不出现。
- **根因（结构性裁切）**：原实现把 `text-overflow: ellipsis` 所需的 `overflow: hidden` 直接加在 `<a class="hot-card__title-link">` 上；而气泡是 `<a>` 的子元素、定位在标题**上方**（`bottom: calc(100% + 8px)`，在 `<a>` 盒子之外）。`overflow:hidden` 会裁掉所有超出盒子的绝对定位后代 → 气泡被无声切掉，与"是否截断"无关。
- **修法**：省略/换行从 `<a>` 下移到**内层 `<span class="hot-card__title-text">`**；`<a>` 只做 `position:relative` 锚点、不再设 overflow。`useIsTruncated` 的 ref 也移到内层 span（测真正被截断的元素）。桌面媒体查询的省略规则同步改到 `.hot-card__title-text`。
- **验证**：`tsc --noEmit` 通过（TSC_EXIT=0）。用户在跑的 Vite HMR 即可见；需桌面≥720px + 标题真正被截断（如 B站 长标题）才触发，短标题走原生 title 兜底（设计如此）。
- **遗留（用户说"后面再商量"）**：气泡仍定位在标题**上方**，第①名那条会压到卡片表头；若用户实测后觉得碍眼，可改到下方或右对齐。

## 桌面奶黄气泡位置定稿（方案② 右上溢出）
- **用户反馈**：气泡在标题正上方会完全挡住自己的表头（"微博·热搜"），带来不适感，不符合定位。明确表态"不挡自己的锚点，要挡就挡其他列"。
- **决策**：经三方案对比（①上方挡表头 / ②右上溢出挡其他列 / ③下方挡下一行），用户拍板**方案②**。
- **首次改动（不到位）**：气泡定位 `left:0` → `right:-10px`，小三角翻到右下。
- **用户实测反馈**：气泡根本没盖住其他列，只是三角从左变到右——根因是 10px 溢出被 grid gap（~20px）完全吸掉，气泡整体仍留在卡片内部。
- **二次修正确认到位**（`client/src/components/HotCard.css`，纯 CSS）：
  - `right:-10px` → `right:-180px`（大幅右溢出 180px，跨过列间距、清晰盖到右侧其他列）
  - 小三角翻回 `left:16px`（指回标题文字，保住气泡↔标题的视觉连接）
  - 依赖前提：`.hot-card` 无 `overflow:hidden`、气泡 `z-index:20`（正数层级，会绘制于邻居列 z-index:auto 之上）
- **边界提醒**：最右一列（B站）无右侧邻居，气泡会探出视口右缘（左半可读，可接受）；若日后觉得盖邻居也不适，可退回方案③（下方）。
- 移动端（<720px）气泡仍 `display:none`（标题自动换行不溢出，避免误触发）。
- **教训**：实现"溢出盖邻居"这类需求，溢出量必须明显大于布局间 gap，否则会被布局吞掉、看起来等于没做。
