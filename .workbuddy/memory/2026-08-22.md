- **教训（项目里再次栽坑）**：当 `.foo:nth-of-type(N)` 用来给"类名相同的兄弟"分别定样式时，**前提是父级下没有其它同名 tag 的兄弟**——一旦同 tag 但不同类名的兄弟掺进来，nth-of-type 会按 tag 类型计数，结果偏移。**保险做法**：要么用 `.foo:nth-child` 数 `.foo` 自身次序（依赖 DOM 顺序严格），要么**直接 inline style**——后者最不会出错，缺点是 JSX 变长。

- **通用经验**：纯 CSS 装饰动画若要"真随机感"，只能用 JS 动态生成 + 定时清除；CSS 只能错峰模拟。用户对"视觉服务内容、不过度"的品味很明确，后续动效默认走"低频+克制+随机"。
