## 优化模式：四处动效打磨（08:43）
- **根因修复（重要）**：App.css 的「主题切换整站过渡」选择器列表里包含 `.hot-card__bubble` 和 `.entry-overlay`，其 `transition: background-color/color/border-color/box-shadow` 会**整体覆盖**这两个元素自身的 transition（CSS transition 不可叠加、后者覆盖前者）→ 气泡显隐的 opacity/transform 过渡、入场退场的 opacity 过渡全部失效（表现为"突然出现/消失"）。修复：从该列表移除这两个选择器，各组件用自己的 transition。
- ① 气泡"弹"出来：基础 transition opacity/transform/visibility 0.45s（退出淡出）；桌面 hover / 手机 is-open 加 `bubble-pop` 动画（0.5s，`cubic-bezier(0.34,1.56,0.64,1)` back-out 贝塞尔带过冲 → 弹跳感）；`prefers-reduced-motion` 下 animation none。
- ② 垃圾桶记录滑出：`.settings-records-wrap` 常驻 DOM，`height: binOpen ? recordsH : 0` + `overflow:hidden` + `transition height 0.35s`；SettingsPanel 用 `useLayoutEffect` 量 `scrollHeight`（开）→ 滑出、收起都顺滑，不再突然撑大面板；内层 `.settings-records` 保留背景色块（去掉原 settings-down 动画与 keyframe）。
- ③ 入场"进入"渐隐恢复：入口动画自身的 `transition: opacity 0.65s ease` 不再被 App.css 覆盖 → 点击进入重新有 0.65s 淡出（此前被覆盖导致瞬隐）。
- ④ 设置面板渐隐消失：SettingsPanel 加 `leaving` 状态 + `requestClose`（点 × / 遮罩统一走），240ms 后真正 onClose；`.settings-mask/.settings-panel` 加 `is-leaving`（opacity→0、panel 下沉 16px）+ transition 0.24s；`prefers-reduced-motion` 下 transition none。
